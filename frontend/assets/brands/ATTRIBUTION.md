# Brand asset attribution

Brand marks in this directory are used only to identify third-party integrations.

- Gmail, GitHub, Notion, NVIDIA, Playwright, Google Drive, Google Calendar, and Slack SVGs were retrieved through the Iconify API from their named icon collections.
- n8n, Ollama, and Cursor marks use the Simple Icons collection through Iconify.
- Microsoft Excel uses the VS Code Icons collection through Iconify.

Sources: https://iconify.design/ and https://simpleicons.org/
